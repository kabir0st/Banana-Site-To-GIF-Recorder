# 🍌 Banana Gif Recorder

A minimal, banana-themed Chrome extension to record smooth GIFs of your tabs.

## Features
- **Smooth Recording**: Captures video and converts to GIF.
- **Banana Theme**: Clean, yellow, and minimalistic UI.
- **Privacy**: Runs entirely locally.

## Usage
1. Click the **Banana** icon.
2. Click **Start Recording**.
3. Wait for the magic (scrolling & processing).
4. Download your GIF!

## Installation
1. Clone repo.
2. Load unpacked in `chrome://extensions`.
